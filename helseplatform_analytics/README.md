# Healthcare Analytics Platform:
# Monitoring Capacity, Performance and Regional Differences in Norway

## 1. Project Background

Norway's healthcare system is facing increasing pressure due to demographic changes, an ageing population, healthcare workforce challenges, and growing demand for healthcare services.

At the same time, healthcare organizations are undergoing digital transformation, where improved use of data and analytics can support more efficient resource planning, quality improvement and evidence-based decision-making.

Healthcare platforms and data-driven solutions require reliable reporting environments that can integrate information from multiple sources and transform complex data into meaningful insights for healthcare professionals and decision makers.

This project demonstrates how healthcare-related data can be transformed into a structured analytics platform for monitoring healthcare capacity, identifying regional differences and supporting management decisions.

---
## 2. Project Objective

The objective of this project is to design and develop a healthcare analytics platform that transforms heterogeneous healthcare datasets into actionable insights.

The project aims to demonstrate a complete data analytics workflow:

- Data collection from public healthcare sources
- Data cleaning and transformation using Python
- Relational database design using SQL
- Development of standardized healthcare indicators
- Interactive reporting and visualization using Power BI
- Generation of insights to support healthcare management decisions

---
## 3. Business Context

Healthcare organizations need reliable and accessible information to answer important operational questions:

- Where are healthcare resources under stress?
- How do healthcare capacities differ between regions?
- Which factors are associated with healthcare service challenges?
- Where should resources and improvement efforts be prioritized?

This project simulates the role of a BI/Data Analyst supporting healthcare management by developing a data product that provides consistent metrics and decision-support insights.
